# yard/: the 3D cut-away yard kit

Loaded by "3D Build" compositions (the render service copies this folder into any project whose
index.html references `yard/`).

- `three.min.js`: three.js r158, MIT (see `THREE_LICENSE`).
- `yardkit.js`: the yard set and animation verbs, written for Animave. Authored in kit coordinates
  (x right, y back from the cut face, z up, metres).
- `tex/*.jpg`: Poly Haven textures (1k diffuse) and the tonemapped `kloofendal_48d_partly_cloudy_puresky`
  sky, all CC0 (polyhaven.com).
- `Nunito.ttf`: captions font, SIL Open Font License 1.1 (see `OFL.txt`).
