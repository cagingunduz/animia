THE FORMAT: an exploded teardown reel. One calm narrator takes one product apart, layer by layer, and names what is
inside and what each part does. The topic is a physical product (a phone, a mouse, a toaster, an e-bike battery, a
smoke detector, a game controller...). If the topic is not a product, pick the object at the heart of it.

STRUCTURE: line 1 names the object ("This is ..."); "let's take it apart"; one line per layer, top to bottom (the
part, then the one fact that makes it interesting: what it does, a real number); a short macro moment on the part that
matters most; the close (it goes back together, with one number for the whole: size, weight, part count).

FACTS: only true, typical facts you are sure of. Numbers as digits in `text` with the spoken form in `say`
("2.4 GHz" / "two point four gigahertz"). If the internals vary by model, say "a typical ..." once. No brand names
unless the user named the product.
VOICE: calm, close, unhurried; sentences of 6-14 words.
LENGTH: 8-14 lines, 90-170 words.
visual_notes: the layers bottom to top with real sizes in mm (e.g. "base shell 62 x 112 x 9 mm; AA cell; board 52 x 70
mm with a sensor chip near the front; wheel Ø18 mm; top shell"), and which label opens on which line.
